A 3D Roblox brainrot game: absurd meme-born brainrots earn money a second on your base while stealers and tsunami waves threaten the catch, with rarities, mutations and rebirths.

## Run it

```sh
rojo build default.project.json --output game.rbxl && mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
